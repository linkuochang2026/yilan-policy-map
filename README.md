# 宜蘭大歌廳①次看全部

宜蘭縣互動地圖。點選鄉鎮、道路或圖釘，查看林國漳候選人的公開政見與相關建設；也可以拖移年齡、選擇職業，看哪些政見與自己有關。

- 網站：<https://linkuochang2026.github.io/yilan-policy-map/>
- 單一檔案 `index.html`，不需要安裝或建置，用瀏覽器直接開啟即可。
- `s/` 資料夾是各頁面（鄉鎮、政見、身分、類別）的分享連結，讓 LINE 等通訊軟體顯示專屬的預覽標題；`og.png` 是預覽圖。
- 右下角有「大字」按鈕，可放大字體給長輩閱讀。

## 說明

- 內容整理自公開資料。候選人尚未當選，這裡是承諾，不是已核定的施政。
- 圖釘位置為約略位置；台62線延伸、高鐵延伸的虛線只是示意。
- 預算金額為估算。
- 網頁字型由 Google Fonts 載入。
